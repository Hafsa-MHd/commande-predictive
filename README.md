# Commande prédictive

Compte-rendu de commande prédictive (MPC), ENSEM, Hafsa Mehdaoui. Deux cas en MATLAB, formulés comme des programmes quadratiques.

- `partie1_supply_chain.m` — chaîne logistique à 5 stocks et 9 flux, horizon 10, 30 pas de simulation.
- `partie2_airbus_a320.m` — modèle discrétisé d'un Airbus A320.

Les figures `p1_fig1.png` à `p2_fig3.png` sont celles du compte-rendu `CR_MEHDAOUI_Hafsa_commande_predective.pdf`.

## Lancer

Ouvrir MATLAB dans ce dossier, puis :

```matlab
partie1_supply_chain
partie2_airbus_a320
```
